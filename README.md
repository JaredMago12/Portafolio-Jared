# Portafolio de Jared Sánchez Sánchez

Ingeniero en Sistemas Computacionales y Software Specialist Senior. Este repositorio contiene mi portafolio personal: una página web con estilo de consola de videojuegos, pensada para reclutadores y clientes.

**Sitio en vivo:** _(agrega aquí tu enlace de Netlify)_

## Qué incluye

- Pantalla de inicio con proyectos destacados que se eligen desde una fila de mosaicos.
- Tarjeta de jugador con mi perfil, trayectoria en un mapa interactivo y experiencia en iLexTech Solutions.
- Biblioteca de proyectos con fichas y galerías de capturas.
- Habilidades en mosaicos, trofeos verificables y formulario de contacto.
- Versión en español e inglés.
- Un trofeo oculto para quien encuentre el código secreto.

## Tecnología

HTML, CSS y JavaScript sin frameworks, en un solo archivo (`index.html`). Las imágenes van incrustadas en el archivo, así que no necesita compilación: Netlify lo publica tal cual. El formulario de contacto usa Netlify Forms.
